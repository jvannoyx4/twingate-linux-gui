# Security

This project is a local desktop wrapper around the official Twingate Linux CLI.
It does not implement its own VPN tunnel or authentication provider.

## Sensitive Data

- Do not commit Twingate CLI logs that include account, network, resource, or
  authentication data.
- Do not commit browser profile data.
- Do not commit access tokens or API keys.

## Reporting Issues

For security-sensitive issues, open a private report through GitHub security
advisories if enabled on the repository. Otherwise contact the maintainer before
posting sensitive details publicly.
